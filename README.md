# Ecommerce-Sales-Customer-Analytics
End-to-End E-Commerce Sales and Customer Analytics using SQL, Python, Excel and Power BI.


## Project Overview
An end-to-end data analytics project focused on analyzing e-commerce sales, customer behavior, product performance, profitability, and business trends.

## Tools & Technologies
- SQL (SQLite / DB Browser for SQLite)
- Python (Pandas, NumPy, Matplotlib)
- Microsoft Excel
- Power BI
- GitHub

## Project Objectives
- Analyze sales and profitability.
- Understand customer purchasing behavior.
- Identify top-performing and loss-making products.
- Analyze monthly, quarterly, and yearly sales trends.
- Evaluate discounts, returns, and delivery performance.
- Generate actionable business recommendations.

## Project Structure
- data/ – Raw and cleaned datasets
- sql/ – SQL scripts and analysis
- python/ – Data cleaning and exploratory analysis
- excel/ – Excel analysis and reports
- powerbi/ – Interactive dashboards
- reports/ – Business insights and recommendations
